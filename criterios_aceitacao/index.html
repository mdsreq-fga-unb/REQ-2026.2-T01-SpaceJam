    Consultar por história¶

    US01Cadastrar perfil (Aluno)

    CA01 (Vínculo Obrigatório): Dado que um novo aluno preenche o formulário de cadastro com todos os dados obrigatórios, Quando insere o código do treinador e aceita os termos, Então o sistema cria a conta e vincula o aluno automaticamente à carteira do treinador (RN02, RN25).

    CA02 (Validação de Dados): Dado que o aluno preenche o cadastro, Quando deixa algum dado obrigatório vazio ou com formato inválido (e-mail, data de nascimento, medidas ou frequência fora de 1 a 7), Então o sistema destaca os campos pendentes e bloqueia a submissão (RN25, RNF14).

    CA03 (Código Inválido): Dado que um novo aluno preenche o formulário de cadastro, Quando insere um código que não corresponde ao do treinador, Então o sistema bloqueia o cadastro e informa que o código é inválido (RN02).

    CA04 (Identificador Repetido): Dado que já existe um usuário com o mesmo apelido ou e-mail, Quando o aluno tenta concluir o cadastro, Então o sistema bloqueia e informa qual dos dois já está em uso (RN24).

    CA05 (Senha Curta): Dado que o aluno preenche a senha, Quando ela tem menos de 6 caracteres, Então o sistema bloqueia o cadastro e informa o tamanho mínimo (RN24).

    CA06 (Termos Não Aceitos): Dado que o aluno preencheu todos os dados, Quando tenta concluir sem aceitar os termos de uso e a política de privacidade, Então o cadastro não é concluído (RN15).

    CA01 (Código de Ativação): Dado que o treinador preenche o formulário de cadastro com todos os dados obrigatórios, Quando informa o código de ativação válido e aceita os termos, Então o sistema cria a conta de treinador e gera o código do treinador, exibido no perfil dele (RN01, RN02, RN25).

    CA02 (Código de Ativação Inválido): Dado que alguém preenche o cadastro de treinador, Quando informa um código de ativação inválido, Então o sistema bloqueia o cadastro e informa que o código é inválido (RN01).

    CA03 (Cadastro Encerrado): Dado que já existe um treinador cadastrado, Quando alguém tenta se cadastrar como treinador, Então o sistema informa que o cadastro de treinador não está disponível e não cria a conta (RN01).

    CA04 (Validação de Dados): Dado que o treinador preenche o cadastro, Quando deixa algum dado obrigatório vazio ou com formato inválido (e-mail ou telefone), Então o sistema destaca os campos pendentes e bloqueia a submissão (RN25, RNF14).

    CA05 (Identificador Repetido): Dado que já existe um usuário com o mesmo apelido ou e-mail, Quando o treinador tenta concluir o cadastro, Então o sistema bloqueia e informa qual dos dois já está em uso (RN24).

    CA06 (Senha Curta): Dado que o treinador preenche a senha, Quando ela tem menos de 6 caracteres, Então o sistema bloqueia o cadastro e informa o tamanho mínimo (RN24).

    CA07 (Termos Não Aceitos): Dado que o treinador preencheu todos os dados, Quando tenta concluir sem aceitar os termos de uso e a política de privacidade, Então o cadastro não é concluído (RN15).

    CA01 (Encerramento de Sessão): Dado que o aluno está autenticado, Quando clica em "Sair", Então o sistema redireciona para a tela de login e o token anterior passa a receber Erro 401 em novas requisições (RNF08).

    CA02 (Acesso Após Sair): Dado que o aluno saiu da conta, Quando tenta abrir uma página que exige login, Então o sistema redireciona para a tela de login (RNF08).

    CA03 (Botão Voltar): Dado que o aluno saiu da conta, Quando usa o botão "voltar" do navegador, Então nenhuma página com dados pessoais é exibida e o sistema redireciona para a tela de login (RNF08).

    CA02 (Credenciais Inválidas): Dado que o aluno informa apelido inexistente ou senha incorreta, Quando aciona o login, Então o sistema não autentica e exibe a mensagem "Apelido ou senha inválidos", sem indicar qual dos dois está errado (RN24).

    CA03 (Termos Pendentes): Dado que existe uma versão dos termos ainda não aceita pelo aluno, Quando ele faz login, Então o sistema exige o aceite antes de liberar as funcionalidades (RN15).

    CA04 (Acesso Restrito): Dado que o aluno está autenticado, Quando tenta acessar uma tela ou endpoint do treinador, Então o sistema retorna Erro 403 (RN03, RNF08).
